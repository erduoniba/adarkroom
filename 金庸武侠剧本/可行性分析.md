# 金庸武侠游戏 — 基于 A Dark Room 的可行性分析

## 一、结论：高度可行

A Dark Room 的核心引擎与金庸武侠题材存在**结构性同构**。改造以文案替换和数值调整为起点，可逐步深化至战斗和事件系统的武侠化重构。下面从 6 个维度分析可行性。

---

## 二、游戏机制对照表

### 2.1 核心循环

| 原版 | 武侠版 | 匹配度 |
|------|--------|--------|
| 黑暗房间 → 点燃篝火 → 保持火势 | 破庙/山洞 → 点燃篝火 → 运功御寒 | **完全匹配** |
| 建造者出现 → 建造村庄 → 招募村民 | 隐世前辈/落难侠客出现 → 建立门派 → 招收弟子 | **完全匹配** |
| 收集资源 → 制作工具/武器 → 探索世界 | 积累资源 → 修炼武功/打造兵器 → 行走江湖 | **完全匹配** |
| 世界地图探索 → 寻找飞船 → 飞向太空 | 江湖地图游历 → 寻找绝世武功/神兵 → 华山论剑/破碎虚空 | **完全匹配** |

### 2.4 武器系统

原版的武器系统 **设计极为精良**，可直接映射：

```
原版武器分级：拳 → 骨矛 → 铁剑 → 钢剑 → 刺刀 → 步枪 → 激光步枪 → 榴弹
武侠武器分级：拳掌 → 木剑 → 青钢剑 → 玄铁剑 → 倚天剑 → 弹指神通 → 六脉神剑 → 降龙十八掌
```

原版已有三种武器类型（`unarmed`/`melee`/`ranged`），完美对应 **拳掌/兵器/暗器内功**。

### 2.5 Perk 系统

原版的 10 个 Perk 可直接映射为武学境界：

| 原版 Perk | 武学映射 |
|-----------|----------|
| boxer → martial artist → unarmed master | 拳法入门 → 拳法精通 → 拳法大成 |
| barbarian | 重剑无锋（兵器伤害加成） |
| slow metabolism | 龟息功（减少食物消耗） |
| desert rat | 寒冰真气（减少饮水消耗） |
| evasive | 凌波微步（闪避提升） |
| precise | 独孤九剑（命中提升） |
| scout | 天眼通（视野扩大） |
| stealthy | 踏雪无痕（减少野外遇敌） |
| gastronome | 北冥神功（药品恢复加成） |

### 2.6 事件系统

这是 **改造空间最大** 的部分。原版的事件系统支持：
- `isAvailable()` — 条件触发（可对应：正邪值、门派好感度、内力等级）
- 多场景分支（`nextScene` + 概率分支）
- 战斗（`combat: true`）+ 特殊机制（`specials`）
- 战利品 + 按钮消耗机制

可直接重构为：
- **江湖奇遇**：遇到黄蓉、杨过、扫地僧…
- **门派事件**：华山论剑、围攻光明顶、少林寺大战
- **正邪抉择**：救人或杀人、加入正道或魔教
- **武学奇遇**：在山洞发现九阳真经、遇到风清扬传授剑法

## 三、改造的技术可行性

### 3.1 无需改动的模块

以下模块**接口稳定，只需替换文案**：
- `engine.js` — 核心引擎完全不变
- `Button.js` — 按钮组件不变
- `state_manager.js` — 状态管理器不变
- `header.js` — 标签导航不变
- `notifications.js` — 通知系统不变
- `events.js` — 事件**引擎**不变（事件**内容**需重写）
- `audio.js` / `audioLibrary.js` — 音频引擎不变（音频文件替换）

### 3.2 需重度改造的模块

| 模块 | 改造程度 | 说明 |
|------|----------|------|
| `room.js` | **重写** | Craftables/TradeGoods 全部替换为武侠道具 |
| `outside.js` | **重度** | 村民 → 弟子，职业 → 修行方向 |
| `path.js` | **中度** | 远征准备 → 行走江湖准备，负重系统可保留 |
| `world.js` | **重度** | 地图 tile → 江湖地标（少林/武当/光明顶/桃花岛）|
| `ship.js` | **重写** | 飞船建造 → 神功修炼/天梯建造 |
| `space.js` | **重写** | 太空飞行 → 破碎虚空/华山论剑 |
| `fabricator.js` | **中度** | 外星科技 → 绝世神兵/武林秘籍 |
| `prestige.js` | **轻** | 二周目 → 转世重修 |
| 事件模块 | **完全重写** | 全部替换为武侠事件 |

### 3.3 CSS 改造

- 配色从暗黑系改为古风色系（米白底 + 墨色文字）
- 字体选用楷体/仿宋
- 装饰元素添加水墨风格边框
- `dark.css`（关灯模式）可保留为"夜行模式"

## 四、风险点

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 战斗系统过简（原版只有 HP + 命中率） | 中 | 可扩展：内力槽、招式冷却、内伤/外伤双轨 |
| 原版线性叙事与金庸开放世界的矛盾 | 低 | 原版本身有随机事件池，只需扩大规模 |
| 版权风险（金庸作品受版权保护） | **高** | 使用泛武侠元素，不直接使用人物名/地名/武功名 |
| 音频资源替换工作量大 | 低 | 先静音运行，后期逐步替换 |
| 移动端适配 | 低 | 此 Fork 已完成移动端适配 |
