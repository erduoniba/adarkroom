# 金庸武侠游戏改造方案

## 游戏名称：《江湖：暗室》（暂定）

> "醒来。头很痛。视线模糊。去点燃篝火。"

---

## 一、故事线设计

### 第一幕：破庙余生
玩家醒来在一座废弃破庙，身受重伤，记忆模糊。需要点燃篝火取暖，收集散落的干柴。一位隐世前辈（原版"建造者"）踉跄入庙，在玩家照料下逐渐恢复。

### 第二幕：建立门派
前辈开始帮助建设：从破庙修整开始，弟子房、药圃、铸造坊、炼丹房逐步建立。流散的江湖人士闻讯而来，加入门派。

### 第三幕：行走江湖
获得罗盘后，玩家可以准备行囊、携带兵器和药物，踏上江湖之路。在野外探索，发现少林寺、武当山、光明顶、桃花岛、绝情谷、黑木崖等地标。

### 第四幕：修成神功
集齐足够资源和武学秘籍后，可以修炼绝世神功。神功大成之日，便是破碎虚空、华山论剑之时。

### 第五幕：破碎虚空（通关）
类似原版太空飞行，以文字动画呈现玩家突破武学巅峰的旅程。

### 二周目：转世重修
保留部分修为，以更高起点重新开始。

## 七、事件系统改造

### 7.1 事件触发条件重定义

原版 `isAvailable()` 可改为检查：
- 正邪值（新增 `character.morality`）
- 声望值（新增 `character.reputation`）
- 内力等级（新增 `character.innerPower`）
- 已解锁的门派建筑
- 已有武器/秘籍

### 7.2 事件类型设计

**江湖偶遇（原版 Global Events）：**
- 遇到采花贼 → 杀之(正) / 放之(邪) / 收为弟子
- 遇到落难侠客 → 施救(得奖励) / 无视
- 遇到神秘商人 → 交易稀有物品
- 遇到挑战者 → 比武 → 胜利(得声望) / 失败(受伤)

**门派事件（原版 Room Events）：**
- 弟子发现藏经阁密室
- 外敌入侵
- 朝廷招安

**江湖事件（原版 Outside Events）：**
- 隔壁门派挑衅
- 武林大会邀请
- 魔教来袭警报

**野外事件（原版 World Encounters）：**
- 山贼打劫 → 战斗
- 发现前人遗迹 → 获得秘籍残卷
- 遇到妖兽 → 战斗(掉落灵骨/内丹)

**特殊剧情（原版 Setpieces）：**
- 华山论剑
- 围攻光明顶
- 少林寺大战
- 襄阳城守城

### 7.3 战斗系统扩展建议

原版战斗只有 HP 和命中率。建议新增：
- **内力槽**（`innerPower`）：使用绝招消耗，打坐恢复
- **招式冷却**：高级武学有独立冷却
- **内伤/外伤双轨**：外伤用金疮药，内伤需运功/丹药
- **属性克制**：阴克阳，柔克刚（可后期迭代）

## 十一、核心注意事项

1. **避免直接使用金庸人名/地名/武功名**。改用泛武侠描述，如"隐世前辈"而非"风清扬"，"绝世剑法"而非"独孤九剑"
2. **保持原版数据模型不变**。不要新增状态字段（除非真的必要），充分利用现有的 `stores`、`character`、`game` 分支
3. **翻译文件是唯一文案入口**。所有中文字符串必须走 `_()`，便于后期多语言扩展
4. **不破坏原有模块接口**。`init()` / `onArrival()` / `tab` / `panel` 签名不变
5. **移动端兼容**。继承此 Fork 已有的移动端适配方案
